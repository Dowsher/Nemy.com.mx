# APK de Visio

- Visio-Mobile-debug.apk: teléfono 0.9.0-live, ARM64.
- Visio-Wear-debug.apk: reloj 0.7.0-feedback, con SDK Samsung.

Ambas instaladas mediante actualización conservando datos. Para otro dispositivo usa `adb -s SERIAL install -r ARCHIVO.apk`; conserva la firma y no desinstales ni borres datos.

En el reloj activa Listo para el teléfono; en el móvil abre En vivo. La prueba física de nuevas actividades, confirmaciones y chasquidos queda al usuario. [Guía actual](../DETECTOR-EN-VIVO.md) · [Hashes y versiones](../ENTREGA.json).
