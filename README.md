# Nemy · código abierto para revisión

Nemy reúne herramientas de acompañamiento y exploración; su contenido no sustituye una atención profesional. Los modelos están en desarrollo y sus resultados individuales no cuentan con validación clínica independiente.

- **DTR-GA**: motor de simulación de estrategias, disponible en [Nemy](https://nemy.com.mx/dtr-ga).
- **TRAZA**: recorridos voluntarios de evaluación y síntesis, en [Nemy](https://nemy.com.mx/traza).
- **UMBRAL**: experiencia educativa sobre consumo, en [Nemy](https://nemy.com.mx/adicciones).
- **CRIO**: página de investigación sobre el frío, en [Nemy](https://nemy.com.mx/crio).
- **CAPTU**: proyecto en desarrollo; no se presenta como producto clínico terminado.

El archivo Nemy-fuente-completa.zip contiene la aplicación completa y las pruebas, sin datos de pacientes, archivos de conversaciones privadas ni credenciales. Las carpetas de cada herramienta permiten examinar sus componentes por separado. Revisa las condiciones de las fuentes e instrumentos antes de reutilizarlos.
