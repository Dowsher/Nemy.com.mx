# Nemy · herramientas para explorar y acompañar

Este repositorio reúne el trabajo de Nemy para revisión técnica. Son herramientas en desarrollo; no sustituyen la atención profesional. Cada carpeta explica su propósito, componentes y límites actuales.

- [TRAZA](TRAZA/): recorrido voluntario de exploración personal. [Abrir TRAZA](https://nemy.com.mx/traza).
- [DTR-GA](DTR-GA/): simulación de estrategias y generación de informes. [Abrir DTR-GA](https://nemy.com.mx/dtr-ga).
- [Visio](VISIO/): prototipo de reloj, teléfono y LED que explora patrones de movimiento para activar señales de acompañamiento. Sus reglas **no identifican sustancias ni demuestran consumo**; falta validar su precisión.

El archivo [Nemy-fuente-completa.zip](Nemy-fuente-completa.zip) contiene el código de la plataforma web completa y sus pruebas. Las carpetas permiten revisar los componentes de cada herramienta. Las aplicaciones y resultados no cuentan con validación clínica independiente. Revisa los derechos de las dependencias y fuentes antes de reutilizar el código; no se declara una licencia general de código abierto.
